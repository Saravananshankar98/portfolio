## 🚀 About This Project

My personal developer portfolio built with **React.js** — showcasing my work experience, technical skills, and the projects I've contributed to across two full-time roles.

### ✨ Features
- Dark, modern UI with glowing cyan accent theme
- Typewriter animation cycling through my roles
- Interactive tabbed Work Experience section with expandable project cards
- Career timeline with animated progress bars
- Smooth scroll-triggered animations
- Fully responsive (mobile, tablet, desktop)
- Glow cursor effect & subtle grid background

## 🖥️ Run Locally

```bash
# 1. Clone the repo
git clone https://github.com/Saravananshankar98/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start dev server
npm start
# Opens at http://localhost:3000
```

---

## 🌐 Deploy to GitHub Pages

```bash
# 1. Make sure your package.json homepage is set:
#    "homepage": "https://saravananshankar98.github.io/portfolio"

# 2. Install gh-pages (already in devDependencies)
npm install

# 3. Deploy
npm run deploy
# This builds the app and pushes to gh-pages branch automatically
```

After deploy, your portfolio will be live at:  
**`https://saravananshankar98.github.io/portfolio`**
